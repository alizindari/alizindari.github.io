The input representation contains features used for different purposes. W_Q transforms it into a query used when the position seeks information. W_K transforms it into a key used when the position is considered as a source. The questions on the slide describe the roles intuitively, not literal natural-language questions encoded in individual coordinates. These are learned linear transformations that can combine features, not necessarily select individual coordinates. Their dot product defines a learned comparison x_4 transpose W_Q W_K transpose x_j. Using x_4 transpose x_j directly would instead compare the original representations by their dot product, which is possible but imposes a more restricted comparison at this layer. Both projection matrices are learned during training and shared across positions. They remain fixed at inference, while their outputs change with the input representations. Every position has both a query and a key. In deeper layers a position's representation already contains context, so the query at is can reflect the preceding phrase. A first-layer representation of is alone does not already know the complete context. The key describes information for matching. The value supplies the information actually mixed, as introduced on the next slide.

Start with the position-4 example from the preceding slides. Compare query q_4 with each key k_j by the dot product q_4 transpose k_j, divide by the square root of their dimension d_k, exponentiate, and normalize over the four positions. This gives a_4j, with nonnegative weights summing to one. Combine the four values with these weights to produce the updated embedding z_4. A value is the transformed embedding v_j transpose = x_j transpose W_V, with W_V the earlier matrix W. Position 4 includes its own key and value even though its self-link was omitted from the preceding figure. Then collect the queries, keys, and values into matrices to express the same operations for all positions. The matrix formula shows basic single-head attention with the causal restriction omitted from its notation for readability. For a causal decoder, earlier positions normalize only over keys at or before their own position. The position-4 equations are exact for the final position of this four-token prompt, because all four keys are available there. Larger query–key dot products give larger weights for this query. This does not guarantee a semantically useful match before learning. Z is an attention output, not final vocabulary probabilities. Learned matrices stay fixed during inference, while queries, keys, values, and weights depend on the prompt. For X of shape T by d, Q and K have shape T by d_k, V has shape T by d_v, A has shape T by T, and Z has shape T by d_v. Multiple heads, output projection, residual connections, normalization, feed-forward blocks, and positional mechanisms are not expanded on this slide.
